# Eighth terminal study: explicit search scope did not improve repair delivery

Local research addendum, October 8, 2026. This has not yet been incorporated into
the saved Kaggle writeup or private resource version10. No final Paper Track
submission, prize performance or general repair improvement is claimed.

The twelve-assignment comparison completes both arms on all six previously
exposed, CPU63-qualified development cases. Both use required Gemma4 31B QAT,
the original native sequential workflow and source-import skill, identical
sampling and output limits, and one shared three-minute task timer. The sole
candidate change appends an instruction requiring explicit repository paths for
content searches. Exact executed code, package members, original compiled child
configurations, API transports and downloaded terminal output reconcile.

Both arms deliver the same clean 503-byte Rich3882 production patch. V21 also
delivers the clean 512-byte FastAPI14361 repair; v22 returns an empty ordinary
timeout on that case. Its unavailable verifier remains unknown. Only one pair
has both verifier outcomes known; none has a discordant pair of known results.
There are no protected-test conflicts. V22 has no verified delivery advantage
and one baseline delivery disadvantage, failing the previously fixed upload
review policy. It is held rather than entered in the main competition.

Manual inspection of the already retained first three complete pairs records
13 explicit-path searches out of 13 observed v22 `rg` calls, versus one out of
12 baseline calls. Two of these three candidate cases invoke `rg`; one does
not. This bounded observation shows instruction uptake without establishing
repair improvement, descriptor-zero behavior in GPU execution or a cause of
the hidden main score. The CPU search controls remain mechanism evidence.

Exploratory timing retains all239 individual call/response observations in the
complete study. Summed tool execution spans approximately0.097–4.364 seconds per
task. The largest response-to-next-call intervals include126.688 seconds on
v22 FastAPI14482,94.177 seconds on v22 Rich3506 and101.134 seconds on v21
Rich3506. These intervals include unmeasured inference, queue and framework
costs. Associated writer events report4354,3233 and3554 total completion
tokens respectively; they are not separately measured reasoning-token counts.
The successful v21 FastAPI production edit starts at167.641 seconds. These
observations motivate a controlled latency experiment, not a causal attribution
of the full interval to thinking or a guaranteed benefit from a shorter cap.

and11 unattempted assignments across eight studies on two exposed panels.
Repeated cases are not pooled as independent trials. Unknown and unattempted
outcomes remain distinct. Recorded scalar reproduction is an internal evidence
consistency check, not independent authentication or a model/grader rerun.
