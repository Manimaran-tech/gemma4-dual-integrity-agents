# Eighth terminal study: instruction uptake without verified repair gain

The fixed comparison repeats the six exposed development cases qualified for
the seventh study. The original 31B model, native compiler, tools, sampling and
shared three-minute task budget remain fixed. The candidate changes only writer
instructions to require explicit search paths. All twelve executions complete;
all executed cells, packages, plans, traces, patches and grader receipts reconcile.

The hypothesis-pipeline baseline produces two verified production repairs in six
executions; the explicit-search candidate produces one in six. Both deliver the
same 503-byte Rich patch. Only the baseline delivers the 512-byte FastAPI repair;
the corresponding candidate execution returns an empty ordinary timeout, whose
verifier remains unknown. Nine verifier outcomes are unknown, and only the shared
success pair has both outcomes known. There are no protected-test conflicts.
These are delivery counts including unknown outcomes, not known-outcome accuracy.
The candidate has no additional verified delivery and is held from main upload.

A bounded capture of the first three pairs records explicit paths in all 13 of
the candidate's observed ripgrep calls, versus one of 12 baseline calls. Two of
the three candidate cases invoke ripgrep; all six captured patches are empty and
their verifiers unknown. This observation establishes instruction uptake within
that capture, not repair benefit across the full study. The GPU input descriptor
is not observed. Native synthetic CPU input controls remain separate evidence.

Post-outcome timing analysis retains 239 individually observed tool intervals
across all twelve executions. Summed observed tool intervals range from 0.097 to
4.364 seconds per task; the largest tool-response-to-next-call gap is 126.688
seconds. The baseline's successful FastAPI edit starts at 167.641 seconds. Gaps
include unseparated inference, queue and framework time; they are not measurements
of pure model thinking. Shell commands are not automatically classified as
source edits. These exploratory scalars motivate further prospective experiments
without establishing a cause of timeouts or the official 0.08 score.

The supplement now retains eight terminal studies: 96 assigned slots, 85
completed executions and 11 unattempted. The first six reuse one exposed panel;
the final two reuse a separate exposed panel. Repeated panels are not pooled as
independent cases. Recorded scalar replay verifies consistency and member byte
identity, without independently authenticating native grading or inference.
No held-out improvement, statistical superiority or prize-level result is claimed.
Pending reasoning-budget experiment outcomes are excluded.
